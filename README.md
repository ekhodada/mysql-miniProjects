# MySQL Mini Projects

A collection of 43 SQL problems solved in MySQL, covering joins, aggregation, subqueries, window functions, string/date manipulation, and conditional logic. Each file contains the original table schema and problem statement as a comment, followed by the query that solves it.

These are practice problems (sourced from LeetCode's SQL/Database track) used to build and demonstrate core SQL fluency ahead of larger, business-context projects such as [`housing-data-sql-cleaning`](https://github.com/ekhodada/housing-data-sql-cleaning).

## Topics Covered

| Topic | Problems |
|---|---|
| **Joins** | Combine Two Tables, Customers Who Never Order, Employee Bonus, Employees Earning More Than Their Managers, Students With Invalid Departments, Consecutive Available Seats |
| **Aggregation (`GROUP BY`, `COUNT`, `SUM`, `AVG`)** | Actors and Directors Who Cooperated At Least Three Times, Ads Performance, Biggest Single Number, Classes More Than 5 Students, Customer Placing the Largest Number of Orders, Duplicate Emails, Game Play Analysis I & II, Queries Quality and Percentage, Reported Posts, User Activity for the Past 30 Days I |
| **Joins + Aggregation** | Average Selling Price, List the Products Ordered in a Period, Number of Comments per Post, Product Sales Analysis I & II, Project Employees I & II, Sales Analysis I, II & III, Students and Examinations, Weather Type in Each Country |
| **Window Functions & Subqueries** | Find the Team Size |
| **Conditional Logic (`CASE WHEN`)** | Reformat Department Table, Triangle Judgement |
| **Date Functions** | Rising Temperature |
| **Other (filtering, string ops, basic logic)** | Article Views I, Big Countries, Delete Duplicate Emails, Find Customer Referee, Friend Requests I: Overall Acceptance Rate, Immediate Food Delivery I, Not Boring Movies, Sales Person, Shortest Distance in a Line, Swap Salary, User Activity for the Past 30 Days II |
